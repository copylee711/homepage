# 协作文档（copylee.cn/docs）

[项目首页](../README.md) · [云盘](drive.md) · [团队](teams.md) · [部署指南](../deploy/README.md)

支持 Markdown 的在线文档，多人实时编辑。列表在主站 `/docs`（导航栏 Docs，登录后显示），
编辑页在 `cloud.copylee.cn/doc/<id>`，链接分享为 `cloud.copylee.cn/d/<token>`。

实时编辑依赖 WebSocket，主站经过的 ESA 免费版不支持，所以编辑页放在直连源站的云盘子域名上；
主站的 `/doc/*`、`/d/*` 由 Caddy 跳转过去。

## 代码

| 位置 | 内容 |
| --- | --- |
| `backend/app/docs.py` | REST 接口、权限计算、WebSocket 协作房间与版本历史 |
| `src/components/editor/MarkdownEditor.vue` | 所见即所得的 Markdown 编辑器，文章、笔记与协作文档共用 |
| `src/components/docs/` | 文档列表、编辑页、分享与版本历史 |
| `src/docs.ts` | 前端接口与实时连接 |

正文是 Yjs 文档，浏览器用 y-websocket 协议连接 `/api/docs/ws/{id}`。服务器用 pycrdt 在内存里为每篇打开的
文档维护一个房间，合并、转发各端的更新，停止编辑 2 秒后写回数据库，最后一人离开时立即写回并释放内存。
后端只运行一个进程，房间不需要跨进程同步；改为多进程前需要先解决这一点。

## 权限

| 身份 | 能做什么 |
| --- | --- |
| 所有者 | 全部操作：编辑、分享、链接设置、删除 |
| 可编辑成员 | 编辑正文与标题、查看与恢复版本历史 |
| 可查看成员 | 只读 |
| 链接（可查看） | 任何持有链接的人只读，包括未登录访客 |
| 链接（登录用户可编辑） | 登录用户可编辑，未登录访客仍然只读 |

- **访客永远不能编辑**：可编辑链接对未登录访客按只读处理，所有写接口与 WebSocket 写入都要求登录。
- 创建文档随云盘开通（或管理员）；被邀请的人不需要开通云盘。
- 成员可以被授予“可分享”：能邀请他人，但授予的权限不超过自己，也不能改动权限更高的成员。
- 链接可设密码、有效期，可随时重新生成让旧链接失效。
- 所有者可以禁止只读的人复制与导出（界面限制，无法阻止截屏或查看源码）。
- 权限在连接时计算，成员或链接设置变化后对在线连接重新计算：失去权限的连接被关闭，
  权限变化的连接被要求重连。只读连接发来的修改由服务器直接丢弃，不依赖前端禁用编辑。

## 版本历史

停顿 10 分钟后重新编辑，或连续编辑超过 30 分钟时，自动把改动前的内容存为版本（每篇保留最近 50 个自动版本），
也可以手动保存。恢复版本是一次新的编辑：把旧内容写入当前文档，所有协作者都会看到，恢复前的内容仍在历史里。

## 图片存储

粘贴、拖入或从工具栏插入的图片可以存到三个地方，在文档列表或文档页“⋯”菜单里设置：

| 去处 | 说明 |
| --- | --- |
| 文档内置存储（默认） | `data_dir/doc-images/<文档>/`，随文档一起删除；单张 10 MiB，每篇 200 MiB |
| 本站图床 | 存入图床并计入图床配额，需要已开通图床并同意使用协议 |
| 第三方图床 | 服务器以 multipart 代为上传，从返回 JSON 中按路径（如 `data.url`）取地址；内置 SM.MS、兰空、Chevereto、ImgBB、EasyImage 的填写模板 |

- 每位用户有默认设置；所有者可以为单篇文档指定去处，此后所有编辑者的图片都按它存放
  （本站图床计入所有者配额，第三方图床使用所有者的配置）。
- 第三方图床的令牌只保存在服务器，读取设置时只显示末尾几位，协作者看不到。
- 代传前解析域名，只允许公网地址，并把连接固定在检查过的 IP 上（TLS 仍按域名校验证书），
  防止借配置访问内网或本机（`backend/app/imagehost.py`）。
- 内置存储的图片地址含随机名，打开图片不校验文档权限，只读链接与导出的 Markdown 中的图片才能显示。
  导出时站内的相对地址会补上域名，在 Typora 等软件里打开也能显示。

## 编辑器

输入 Markdown 语法即时变成格式，`/` 呼出插入菜单，`Ctrl+/` 切换源码模式。快捷键与 Typora 基本一致：

| 操作 | 快捷键 |
| --- | --- |
| 公式块 | `Ctrl+M`（或 `Ctrl+Shift+M`），插入后直接进入公式编辑框，`Ctrl+Enter` 完成 |
| 行内公式 | `Ctrl+Shift+E`，或直接输入 `$公式$` |
| 代码块 | `Ctrl+Shift+K`，或一行写 ```` ```语言 ```` 后回车 |
| 标题 / 正文 | `Ctrl+Alt+1`–`6` / `Ctrl+Alt+0`（`Ctrl+数字` 被浏览器用于切换标签页） |
| 引用、有序列表、无序列表、待办 | `Ctrl+Shift+Q`、`Ctrl+Shift+[`、`Ctrl+Shift+]`、`Ctrl+Shift+X` |
| 链接、行内代码、表格 | `Ctrl+K`、``Ctrl+Shift+` ``、`Ctrl+Alt+T` |
| 标题 | `# ` 到 `###### ` 后接空格（全角空格也可以）；在标题开头再输入 `#` 提升一级 |

工具栏的表情按钮按类别列出常用表情，最近用过的记在本机。

文档栏的头像列出所有在线连接，自己排在最前；同一个人在多台设备上打开时分别列出并标注设备（电脑、手机、平板）。
点开后可以跳到正在编辑的人的光标处（光标标签上带有连接编号，见 `renderCaret`），所有者还可以从这里打开分享设置。

“插入视频”可以粘贴哔哩哔哩、YouTube、Vimeo、腾讯视频、优酷的页面链接或 `<iframe>` 嵌入代码，
也可以是 `.mp4`、`.webm` 等视频文件地址。嵌入默认铺满正文宽度、16:9，保存为 `<iframe>`；
只允许这几家的播放器地址（`src/components/editor/embeds.ts` 与 `backend/app/rendering.py` 的白名单），
发布页给 iframe 统一加上 `sandbox`，哔哩哔哩默认关闭自动播放。

图片、视频与嵌入都可以拖动左右边缘或下角缩放，保持比例。调整过宽度的图片保存为 `<img width>`，
视频保存为 `<video controls>`；发布页的渲染白名单允许这些标签与 `width` 属性，不允许 `autoplay`。

文章与笔记也使用这个编辑器。内容含有其他原始 HTML（`<img>`、`<video>` 除外）、脚注、引用式链接或夹在文字中的 `$$行内公式$$` 时，
可视化编辑无法原样保留，编辑器会自动进入源码模式。正文里的 `$` 保存为 `\$`，发布后不会被误当成公式。

手机上编辑时，工具栏停靠在软键盘上方；触屏不显示选中浮动菜单，以免与系统菜单冲突。

## 团队文档

属于团队的文档（`doc.team_id`）权限还取决于团队角色，左侧栏多一个“文件”页显示团队文件树，
正文里输入 `[[` 可以引用团队文件，见 [团队](teams.md)。
