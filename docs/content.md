## 内容更新

主页与后台由 Vue 提供，文章列表与正文由 FastAPI 输出完整 HTML。后台管理主页资料、入口卡片、仓库分组与隐藏规则，以及文章草稿和发布内容。Notion / Notes 入口保留，本站文章使用 Articles 入口。

页面打开时读取最新内容，可见时每 30 秒检查版本，切回页面时立即检查；版本未变化时不重复拉取。失败后退避重试并保留已加载内容，首次加载失败显示重试入口。阅读中的正文不会自动替换，新版本发布时提示刷新，撤下时清除正文并显示不可用状态。

GitHub 仓库由后端每 15 分钟同步，后台支持手动刷新。前端构建不访问 GitHub。

## 接口与发布规则

- `/api/site` 返回 `{site, revision}`；公开入口不包含隐藏卡片。
- `/api/repos` 返回 `{items, revision}`，GitHub 同步状态仅在后台显示。
- `/api/posts` 返回 `{items, revision}`，不包含草稿或正文；`/api/posts/{slug}` 返回公开快照。
- `/api/version` 返回 `{site, repos, posts}`。公开页面每 30 秒比较版本，无变化不重新请求内容；后台页不轮询。
- 文章编辑与发布使用不同快照。保存草稿不会增加公开文章版本；发布/撤下增加版本。固定链接首次发布后锁定。
- 设置保存和文章修改/发布/撤下必须携带 `revision`，冲突返回 409，前端保留输入，用户重新加载后再决定。
- 写请求携带允许的 `Origin` 与 `X-CSRF-Token`；登录只校验来源，登录后 `/api/auth/me` 返回会话 CSRF。
- 图片上传使用原始文件请求体，POST `/api/admin/media`，返回 `{url}`。大小上限 10 MiB，格式按内容识别，不信任扩展名。
- 仓库完整分页成功才替换缓存。同步失败保留缓存；切换 GitHub 账号时清空旧账号列表，等待新账号同步。多个分组前缀匹配时归入首个匹配分组。

## 路由

| 路径 | 用途 |
| --- | --- |
| `/` | 主页 |
| `/admin` | 管理后台 |
| `/posts`、`/posts/{slug}` | 文章列表与正文 |
| `/api/*` | 公开内容、认证与管理 API |
| `/media/*` | 上传图片 |
| `/sitemap.xml`、`/robots.txt` | 搜索引擎入口 |

文章 HTML 包含正文、标题、描述、canonical、Open Graph 与结构化数据。草稿不进入公开接口或 sitemap；不存在及已撤下的文章返回 HTTP 404。Markdown 禁用原始 HTML，渲染结果统一清理；后台预览与公开正文共用渲染逻辑。上传图片为公开资源，草稿权限不延伸到图片 URL。
