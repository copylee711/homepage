## 内容更新

主页与后台由 Vue 提供，文章、笔记的列表与正文由 FastAPI 输出完整 HTML。后台管理主页资料、社交主页、入口卡片、仓库分组与隐藏规则、文章草稿和发布内容，以及笔记。

## 笔记

笔记有两种来源：

- **GitHub 仓库**：后台「笔记管理」配置仓库（owner/name）、分支与排除规则。服务每 30 分钟用一次 API 请求检查分支最新提交，有变化才从 codeload.github.com 下载整个仓库归档（服务器访问 raw.githubusercontent.com 不稳定）。Markdown 中引用的仓库内图片保存到 `media/notes/`，相对 `.md` 链接改写为站内 `/notes/…` 地址。仓库笔记的内容以 GitHub 为准，后台只能切换公开状态；文件删除后笔记随之删除。新笔记是否自动公开可配置，文件名以 draft 开头的笔记始终默认隐藏。
- **后台手写**：在「笔记管理」新建，可上传图片、预览，保存即生效。

公式使用 `$…$` / `$$…$$`，后端保留 TeX 原文，含公式的页面按需加载 KaTeX。Markdown 中的 HTML 经 nh3 白名单清洗后输出。

页面打开时读取最新内容，可见时每 30 秒检查版本，切回页面时立即检查；版本未变化时不重复拉取。失败后退避重试并保留已加载内容，首次加载失败显示重试入口。阅读中的正文不会自动替换，新版本发布时提示刷新，撤下时清除正文并显示不可用状态。

GitHub 仓库由后端每 15 分钟同步，后台支持手动刷新。前端构建不访问 GitHub。

## 接口与发布规则

- `/api/site` 返回 `{site, revision}`；公开入口不包含隐藏卡片。
- `/api/repos` 返回 `{items, revision}`，GitHub 同步状态仅在后台显示。
- `/api/posts` 返回 `{items, revision}`，不包含草稿或正文；`/api/posts/{slug}` 返回公开快照。
- `/api/version` 返回 `{site, repos, posts}`。公开页面每 30 秒比较版本，无变化不重新请求内容；后台页不轮询。
- 文章编辑与发布使用不同快照。保存草稿不会增加公开文章版本；发布/撤下增加版本。固定链接首次发布后锁定。
- 设置保存和文章修改/发布/撤下必须携带 `revision`，冲突返回 409，前端保留输入，用户重新加载后再决定。
- 写请求携带允许的 `Origin` 与 `X-CSRF-Token`；登录只校验来源，登录后 `/api/auth/me` 返回会话 CSRF。
- 图片上传使用原始文件请求体，POST `/api/admin/media`，图片存入[图床](image-host.md)，返回图床地址 `{url}`。大小上限 20 MiB，格式按内容识别，不信任扩展名。
- 仓库完整分页成功才替换缓存。同步失败保留缓存；切换 GitHub 账号时清空旧账号列表，等待新账号同步。多个分组前缀匹配时归入首个匹配分组。

## 路由

| 路径 | 用途 |
| --- | --- |
| `/` | 主页 |
| `/admin` | 管理后台 |
| `/posts`、`/posts/{slug}` | 文章列表与正文 |
| `/api/*` | 公开内容、认证与管理 API |
| `/media/*` | 旧上传图片、GitHub 笔记图片与头像 |
| `/images/*` | 图床图片（仅开发环境；生产由 `image.copylee.cn` 提供） |
| `/sitemap.xml`、`/robots.txt` | 搜索引擎入口 |

文章 HTML 包含正文、标题、描述、canonical、Open Graph 与结构化数据。草稿不进入公开接口或 sitemap；不存在及已撤下的文章返回 HTTP 404。Markdown 禁用原始 HTML，渲染结果统一清理；后台预览与公开正文共用渲染逻辑。上传图片为公开资源，草稿权限不延伸到图片 URL。

## 访客账户

访客可用常见邮箱（后台「用户与邮件」配置允许的域名）注册，邮箱验证码通过站长配置的 SMTP 邮箱发送。注册默认关闭，配置好 SMTP 并发送测试邮件成功后再开启。

- 登录后可以收藏笔记与文章、自动记录浏览历史（最多 200 条，可清空）、上传头像（不超过 2 MiB，统一裁成 256×256 WebP 并去除元数据）。
- SCUT 通知的已读/未读状态在登录后同步到账户：首次登录合并本机已有标记，之后的修改自动上传；未登录时仍保存在浏览器本地。
- 验证码 10 分钟有效、最多尝试 5 次；同一邮箱 60 秒内只能发送一次，同一 IP 每小时最多 10 次，全站每日总量由后台限制。
- 找回密码不暴露邮箱是否注册；修改密码会退出其他设备；用户可在账户设置中永久删除账户及全部数据。
- SMTP 授权码与两步验证密钥使用同一个 `2fa.key` 加密保存，备份包含该密钥与用户头像。
- 访客账户与管理员认证完全分离：独立 Cookie、会话表和限流。管理员可在后台停用或删除用户。
