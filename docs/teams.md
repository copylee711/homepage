# 团队（cloud.copylee.cn/t/&lt;代号&gt;）

[项目首页](../README.md) · [云盘](drive.md) · [协作文档](docs.md)

团队是几个人一起做一件事时的共享空间，比如打数模比赛：大家把资料、源代码和其他资源放在一起，
一边写协作文档一边引用这些文件。导航栏里叫 Teams，界面上叫“团队”。原来的 Projects 仍然是作品展示。

## 页面

| 地址 | 内容 |
| --- | --- |
| `copylee.cn/teams` | 我创建的和我加入的团队，可以新建团队 |
| `cloud.copylee.cn/t/<代号>` | 团队工作区：左侧文件树（文件夹、文件、文档混排），右侧是当前文件夹的文件管理 |
| `cloud.copylee.cn/doc/<id>` | 团队文档仍在原编辑页打开，左侧多一栏团队文件树 |

工作区和编辑页都放在云盘子域名，大文件上传不经过 CDN，文档的 WebSocket 也能直连。主站的 `/t/*` 由 Caddy 跳转过去。
代号是 10 位小写字母和数字，创建时生成，不会改变，WebDAV 地址也用它。

## 存储与配额

- 创建团队时从创建者（所有者）的总配额里**划拨**一块固定空间，默认 1 GB（剩余不足 1 GB 时默认填剩余的一半），
  最少 10 MB，最多为当前剩余配额。空着也算占用：`storage.shared_used` = 图床 + 个人云盘 + 名下团队的划拨额。
- 所有者可以调整额度：调大不能超过自己的剩余配额，调小不能小于团队已用量。
- 团队空间满了只拒绝新的上传，个人云盘不受影响。
- 文件放在 `drive_dir/.teams/<代号>/`，由 `vfs.TeamDrive` 管理。它是只有一个本地挂载点的 `Drive`，
  所以网页、WebDAV 的路径校验、配额检查与审计都复用云盘的实现，用量记在 `team.used_bytes`。
- 协作文档本身存在数据库里，不占团队空间（与个人文档一致）。

## 成员与权限

沿用协作文档的 edit / view：

| 身份 | 文件 | 团队文档 | 管理 |
| --- | --- | --- | --- |
| 所有者 | 读写 | 等同每篇文档的所有者 | 成员、额度、改名、删除团队 |
| 可编辑成员 | 上传、新建、改名、移动、删除、在线编辑文本 | 新建文档；编辑全部团队文档 | 无 |
| 只读成员 | 浏览、预览、下载 | 只读 | 无 |

- 创建团队需要已开通云盘并同意使用协议（要从自己的配额里划拨空间）。被邀请的成员不需要开通云盘。
- 邀请时从好友列表里选人，也可以直接填邮箱（对方须已注册）。每个团队最多 50 位成员。
- 团队文档的权限取“团队角色”和“文档自身的成员或链接”中较高的一个，文档仍然可以单独分享给团队外的人。
- 文档的创建者在团队内对这篇文档也是所有者。成员退出或被移除时，他在团队里建的文档转给团队所有者。
- 删除团队会删除全部文件和团队文档，无法恢复。

## 文件树与在线编辑

- `GET /api/teams/<代号>/tree` 一次返回全部文件夹、文件（上限 5000 项）与文档，文件树在前端展开折叠。
- 文件管理复用云盘的 `DriveFiles` 组件：云盘的文件接口都接受 `team=<代号>` 参数，
  这时操作的是团队空间（上传会话 `drive_upload.team_id` 记下所属团队）。团队里不提供外链分享。
- 文本文件（代码、`.txt`、`.md`、`.gitignore`、`.json` 等，2 MiB 以内、UTF-8）可以在线编辑。
  **不做实时协作**：打开时记下文件的版本（大小与修改时间），保存时带上；期间被别人改过就提示冲突，
  可以选择覆盖或放弃。这样不需要常驻内存的协作房间，服务器负担与普通上传相同。

## 本地映射（WebDAV）

每个团队有单独的 WebDAV 根：`https://dav.copylee.cn/t/<代号>/`。在 Windows 资源管理器里
“映射网络驱动器”填这个地址，就能把团队映射成一个盘，根目录就是团队本身。

- 登录名可以是站点邮箱或云盘登录名，密码是**应用密码**。没有开通云盘的成员也可以在团队页“映射到本地”里
  生成应用密码（与云盘设置里的是同一套凭据），但这个密码只能访问自己所在的团队，访问个人云盘仍要求开通云盘。
- 权限按团队角色计算，只读成员映射出来也是只读。
- `https://dav.copylee.cn/t/` 列出自己所在的全部团队（按代号）。
- 团队文档在所在文件夹里显示为只读的 `标题.md`，内容是正文的 Markdown 快照，不占配额。
  快照由正在编辑的浏览器在停止输入几秒后上传（`PUT /api/docs/<id>/markdown`，只接受可编辑的人）；
  与真实文件重名时文件名加上 “（文档）”。
- 实现上是 WsgiDAV 的第二个 provider（挂在 `/t`），个人云盘里名为 `t` 的顶层目录在 WebDAV 里会被它遮住
  （上线前检查过，线上没有这样的目录）。

## 文档里引用团队文件

- 在团队文档里输入 `[[` 弹出团队文件列表，按名字筛选，回车插入。
- 显示为文件卡片：图标、文件名、大小；点击预览或下载。`![[图.png]]` 直接嵌入图片。
- Markdown 里保存为 `[[文件名]]`；团队里有同名文件时自动写成完整路径 `[[/资料/文件名]]`。
  解析时以 `/` 开头的按路径找，否则按文件名找（多个同名取路径最短的一个）。
  文件被删除或改名后卡片显示“找不到文件”。
- 不属于团队的文档里，`[[…]]` 按普通文字保留。
