# 生物配图搜索源

- [EMBL-EBI](https://www.ebi.ac.uk/) — 分子生物学和生物信息学数据资源。
- [RCSB PDB](https://www.rcsb.org/) — 蛋白质与核酸的三维结构，按名称或 PDB ID 查找。
- [Wikimedia Commons](https://commons.wikimedia.org/wiki/Category:Biological_diagrams) — 生物结构示意图。查看文件页许可。

先按具体概念和图示关系检索。选图前核对图注、适用范围、作者和文件许可。来源页面与图片直链分别保留。
